## 简介
这门课程主要学习 C++ 的基础语法与程序设计方法，内容通常包括数据类型、流程控制、数组、函数、指针，以及面向对象中的继承和多态等。具体教学范围以任课教师当学期的教学安排为准。

## 分值占比
课程成绩通常由平时学习、在线实验和期末考试等部分组成，不同教师和学期的比例可能不同。建议在开课后尽早确认课程大纲，并记录作业、实验和考试各自的权重。

## 实验
实验与课程内容联系紧密，因此在本文中一并介绍。

实验通常是在 Python123 平台完成 C++ 编程题。尽量独立完成并及时订正错误，比只追求平台分数更有助于准备期末考试。

## 考试与复习
学院通常会统一安排期末考试。常见复习方向包括基础语法、程序阅读、代码填空和手写程序，实际题型与范围以当学期通知为准。

建议重新独立完成课程实验中的典型题目，并整理数组、函数、指针和类等容易出错的知识点。平时如果确实是独立完成实验，手写代码部分通常会更容易适应。

## 开发环境
可以使用 Visual Studio，也可以使用体积更轻的 VS Code。VS Code 本身不包含 C++ 编译器，需要另外安装并配置 MinGW-w64 等工具链；初学者应先确保能够完成编译、运行和调试，再考虑编辑器扩展。
